# Contributions

The repository is public for inspection and use under the included licenses. Public visibility does not grant write access.

Submit proposed changes through a fork and pull request. Describe the problem, include reproducible steps, and report which Blender/Python/platform combinations were tested. Do not include compiled modules, credentials, private scenes or unlicensed assets.

The maintainer reviews and decides which changes to merge. No automatic merge process is enabled. Contributions must be compatible with GPL-3.0-or-later and preserve third-party attribution. This workflow does not restrict the license rights to use, modify or redistribute your own copy.
