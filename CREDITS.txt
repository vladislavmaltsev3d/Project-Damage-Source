Ivy growth — conceptual references
Thomas Luft, Ivy Generator (2007): classic growth, adhesion and gravity model.
CrazyIvy: inspiration for growth/collision and orientation improvements.
The current source describes an independent implementation. These entries
credit ideas and do not claim a verified GitHub source-code import or license
for CrazyIvy. No repository URL was supplied for these conceptual references.

Rough break faces / noisy Boolean interfaces — conceptual reference
FxForge, Destruction Tools: shared noisy-grid cutter idea. Project Damage's
implementation is independent, according to the project author (2026-11-04);
Destruction Tools source is not bundled. Credit is for the idea, not copied code.

Bricks Generator reference
Trowel Core geometry-node setup, supplied by the project author.
The supplied Python file identifies author 23e and contains a copyright notice
for l3d. Its node graphs were studied for row spacing, bond alternation, end
pieces, trim and mortar behavior. Project Damage uses an independent C++
implementation; the supplied node groups and brick assets are not bundled.
